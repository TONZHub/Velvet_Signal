Compatibility evidence · early field results

VS-Bench separates memory from reasoning.

A model can receive the correct current context and still reason badly. VS-Bench scores those layers separately so Velvet Signal does not get credit for a model's intelligence—or blamed for a model's ordinary hallucination.

These are early observed runs from development, not a statistically powered benchmark. Manual patch-injection tests and local Ollama RAG tests are labeled separately.

What gets scored

Six separate layers.

01 · StorageDid the patch survive?

Approved patches should remain in the user-controlled ledger across terminal, Ollama, code, and computer restarts.

02 · EligibilityShould this claim be active?

Locked, expired, rejected, replaced, or displaced conflicting claims should never enter active retrieval.

03 · ResolutionWhat changed—and why?

Explicit replaces, narrows, confirms, and conflicts links must produce the right active set and an inspectable decision trail.

04 · RetrievalDid the right claims rank?

Semantic and lexical scoring are inspected only after relationship resolution.

05 · ProvenanceCan we inspect why?

Patch IDs, claim IDs, source IDs, dates, scores, and relationship actions remain attached to context.

06 · ReasoningDid the model apply it?

This is the model's job. A wrong inference after correct retrieval is recorded as model reasoning failure, not hidden as a generic RAG failure.

Observed retrieval proof

Semantic retrieval found the rule that shared no keywords.

For the five-day cooked-chicken prompt, Velvet Signal retrieved pantry-003/P-06, pantry-003/P-01, and pantry-003/P-08. In the observed inspection run, P-08 had a lexical score of 0 and still ranked third through semantic similarity.

“The model can forget the conversation. Velvet Signal can still remember the approved update.”
Synthetic relationship suite

Four meanings. Zero inference by vibes.

The deterministic suite uses harmless UI facts to test replaces, narrows, confirms, and conflicts. Replacement and conflict withhold the older statement while retaining its ID and history; narrowing and confirmation keep both claims active with explicit scoped instructions. Reverse-time links and missing targets are refused. Historical wording may retrieve its linked replacement, but the displaced statement is never injected as active truth. If the replacement later expires, its tombstone prevents the old claim from quietly resurrecting. Embeddings rank the surviving claims—they never decide what a relationship means.
